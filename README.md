# Радар новичков

Прототип для слова «НОВИЧОК»: сервис для HR и руководителей подразделений, который показывает, кого из людей в первых 90 днях нужно догнать сегодня, и ставит задачу в Битрикс24.

## Запуск

Откройте `dist/index.html` в браузере. Сервера и установки не нужны.

Пересборка и тесты (Node 18+):

    node build.js
    node --test tests/scoring.test.js

## Состав

- `src/scoring.js` — контрольные точки (дни 1, 3, 7, 14, 30, 60, 90), правила риска, сборка запроса `tasks.task.add`.
- `src/data.js` — вымышленные данные: 24 новичка в четырёх подразделениях, генерация детерминирована.
- `src/app.js`, `src/app.html` — интерфейс, без фреймворков.
- `tests/scoring.test.js` — 12 тестов логики.
- `build.js` — собирает всё в один файл `dist/index.html`.

## Правила риска (0–100)

| Сигнал | Баллы |
|---|---|
| Пульс-опрос: средняя оценка ≤ 2,5 / ≤ 3,5 | 35 / 15 |
| Вопрос «вижу себя в компании» ≤ 2 | 15 |
| Оценка упала на 1 и больше между опросами | 10 |
| Пульс-опрос не заполнен вовремя | 15 |
| Нет наставника с 3-го дня | 15 |
| Пропущенная встреча (до 3 штук) | 10 за каждую |
| Два и больше отсутствия или опоздания за 14 дней | 15 |

50 и выше: позвонить сегодня. 25–49: присмотреться. Меньше: в норме. Пороги и веса подобраны по здравому смыслу, а не по данным компании. Их нужно калибровать на фактических увольнениях.

## Битрикс24

Задача собирается как `tasks.task.add` (заголовок, описание с причинами, ответственный, срок, теги). Если на вкладке «Задачи в Битрикс24» указан адрес входящего вебхука, запрос уходит туда. Без адреса задача остаётся в журнале, JSON можно скопировать. Реальный портал не проверялся.
